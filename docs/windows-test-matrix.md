# Windows 10 验收矩阵

## 使用边界

本文把可在当前开发环境执行的静态或集成验证，与必须在 Windows 10 虚拟机或专用测试机执行的真实验收分开记录。表中的“预期”来自 [设计文档](design.md)；除非在执行记录中另有填写，均不代表已经通过真实 Windows 验收。

首次部署只能使用可还原快照的 Windows 10 虚拟机或专用测试机，不能部署到唯一可用的管理员电脑或生产笔记本。真实验收至少准备：有效策略 v3、有效策略 v2、短有效期策略、错误签名包，以及包含未授权 USB 存储、受控网卡、光驱和扫描样本的测试设备。

审计事件以业务语义描述，不依赖尚未稳定的事件枚举名称。应核对事件的时间、设备 ID、会话或用户摘要、策略版本、资源摘要、动作、结果以及 hash chain 前后关系。

## 当前可做的静态与集成验证

这些检查不要求 Windows 登录桌面、真实 Credential Provider、真实服务控制器或物理设备；它们只能证明策略和服务契约，不能替代下一节的实际验收。

| 覆盖项 | 前置条件 | 操作 | 预期登录状态 | 预期设备状态 | 预期审计事件 |
| --- | --- | --- | --- | --- | --- |
| 无策略、到期时间与签名 | 构造无活动策略、已签名有效包、错误签名包和已过期的包 | 调用策略导入与授权判断测试 | 无策略、签名错误或已过期时为 `Denied`；有效包为 `Allowed` | 未授权结论不产生允许设备的结果 | 导入接受或拒绝、授权允许或拒绝的语义记录可被断言 |
| 版本回退与时间回拨 | 活动策略为 A v3，持久化最后可信时间 | 尝试导入 A v2；分别在容差内和超过容差的回拨时间调用授权判断 | v2 被拒绝后仍按 v3 的授权结论；超过容差为 `Denied` | 回退包不得替换 v3 的派生设备规则；回拨拒绝对应默认拒绝处置 | 版本回退拒绝、时间回拨和授权状态变化 |
| 策略介质导入筛选与原子替换 | 使用临时目录模拟卷根目录，准备固定文件名、错误文件名和无效内容 | 调用 `import_from_policy_media` 或等价集成测试 | 只有合法根目录包可令服务返回允许；未找到或无效包保持拒绝 | 失败导入不得改变既有策略对应的设备规则 | 扫描本地卷、未找到、解析或验签失败、导入拒绝或成功 |
| 登录组件状态映射 | 模拟服务返回 `Allowed`、策略拒绝、超时和协议错误 | 运行 Filter/Provider 的单元或集成测试 | 仅 `Allowed` 放行系统密码、PIN、Hello 等提供方；其余仅 Anchor Guard 导入项 | 不直接控制设备 | 服务不可用或协议异常应被表示为拒绝路径；真实服务审计留待 Windows 验收 |
| 默认拒绝与扫描规则 | 构造仅含显式允许项的策略、未命中设备和稳定扫描文件 | 运行策略执行与扫描器测试，检查扫描前后文件哈希 | 授权有效时为 `Allowed` | 未匹配 USB 存储、网卡和刻录对象的处置为禁用或拒绝；扫描文件内容不变 | 设备识别与处置结果；扫描命中含路径摘要、文件哈希、命中规则和扫描结果 |
| 审计链与在线分页 | 创建完整链、修改或删除中间事件的副本，以及不可读数据库副本 | 调用服务审计查询和 `Store::audit_chain_healthy` | 不适用，查询不得改变现有授权结论 | 不适用，查询不得改写设备状态 | 完整链返回事件与 `chain_healthy=true`；断链或不可读库返回异常或不可用；分页游标不重复、不跳过 |
| 扫描结果事件 | 有效策略指定受控目录和 `file_types`，目录内放入命中样本、未命中样本和其他扩展名文件 | 依次写入三类文件后检查审计事件与扫描索引 | 保持正常登录和解锁 | 文件不隔离、不删除、不改写 | 命中写 `scan_hit`，未命中写 `scan_completed`，未声明扩展名不扫描；事件带路径、哈希、规则、策略版本和会话级操作者 |
| 设备差异处置与审计去重 | 构造与策略一致、与策略不一致的设备观测，以及被策略允许但处于禁用状态的 USB 存储 | 连续执行多轮处置编排，核对执行器调用次数与审计事件数量 | 授权有效时为 `Allowed` | 与策略一致的设备不产生处置；状态恢复到与策略一致后不再被处置 | 接入、移除和处置结果各只记录一次；重复核对不产生新事件；同一拒绝原因和同一失败原因不重复记录 |
